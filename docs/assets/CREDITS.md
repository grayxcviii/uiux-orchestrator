# VELTORA Noir — perfume campaign

`veltora-perfume.png` was generated with the built-in image generation tool for this fictional luxury perfume campaign. The exact generation prompt and provenance are recorded in [IMAGE_PROMPT.md](../showcase/IMAGE_PROMPT.md). The source image is committed locally; no runtime download or generation is needed.

The other `veltora-*` images and films are browser captures of the product photograph composed with HTML/CSS typography and a deterministic photographic motion timeline. The source code is original project work under the repository MIT licence. System fonts are used; no third-party stock photography, downloaded fonts or 3D models are included.

VELTORA, Noir, the fragrance notes and product details are illustrative. This is an authored showcase, not a real product or an independently evaluated orchestrator run. [Source and reproduction notes](../showcase/README.md).
